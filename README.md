# Yashvi Patel — Personal Portfolio Website

Responsive portfolio built with React, Tailwind CSS, Framer Motion, and Vite, using the project details in Yashvi Patel's résumé.

## Run locally

Requirements: Node.js 22+ and npm.

```bash
npm install
npm run dev
```

Build and preview the production site with `npm run build` and `npm run preview`.

## Deploy to Vercel

Import the project into Vercel as a Vite app. Use `npm run build` as the build command and `dist` as the output directory. `vercel.json` includes an SPA route fallback.

The GitHub Actions workflow builds pull requests and deploys pushes to `main`. Add `VERCEL_TOKEN`, `VERCEL_ORG_ID`, and `VERCEL_PROJECT_ID` as repository secrets after connecting the project to Vercel.
